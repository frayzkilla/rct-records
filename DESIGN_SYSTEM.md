# RAW CROWNZ — дизайн-система

## Направление

Смелый музыкальный брутализм на тёмном фоне: плакатная композиция, огромные буквы, жёсткие рамки, прямоугольные кнопки, контрастные блоки и графика реального звука. Оранжевый отсылает к SoundCloud; собственный характер задают MARS, нарисованные короны и типографические наложения. Декоративные дубли надписей скрыты от скринридеров.

Сетка отступов: 4, 8, 12, 16, 24, 32, 48, 64, 96 px. Максимальная ширина контента 1440 px. Поля: 48 px на больших экранах, 24 px на планшете, 16 px на телефоне. Радиус основных элементов — 0; круг допускается для кнопки воспроизведения.

## Типографика и графика

MARSNEVENEKSK-Regular.otf подключается локально с font-display: swap. Используется для бренда и больших латинских плакатных надписей. Кириллические заголовки и интерфейс используют Arial / sans-serif; метаданные — Courier New / monospace. Размер плакатного заголовка адаптивный: 64–180 px. Заголовки страниц 44–96 px, карточек 20–28 px, текст 16 px, метаданные 12–14 px. Не ограничивать длину названий в деталях; в плеере использовать ellipsis.

Исходный лист корон находится в frontend/src/assets/crowns.svg (предоставленный crowns.svg). Отдельные короны показываются через SVG viewBox без изменения исходника. Обложки квадратные; при отсутствии или ошибке изображения показывается графический блок с короной. Не подменять реальные релизы демонстрационными данными.

## Компоненты

- Header: логотип, активный раздел; на телефоне раскрывающаяся навигация с aria-expanded.
- Page heading: индекс раздела, крупное название, описание, счётчик.
- Track row: номер, play/pause, обложка, ссылка на трек, ссылка на артиста, ссылка на альбом при наличии, реальная waveform.
- Artist / album card: квадратная обложка, видимые ссылки, рамка, смещение тени при hover.
- Entity hero: обложка, тип сущности, название, связанные сущности, контекстная кнопка «Слушать».
- Breadcrumbs: каталог → сущность; для трека при наличии альбома включать его в цепочку.
- Player: закреплён внизу, предыдущий / play / следующий, реальная waveform, время, громкость, ссылки на трек, артиста и альбом, раскрываемая очередь. Контент страницы имеет нижний отступ.
- Feedback: состояния загрузки, пустого каталога, отсутствующей сущности, ошибки API с повторным запросом, ошибки аудио.

## Сквозная навигация

Маршруты: /, /beats, /beats/:id, /artists, /artists/:id, /albums, /albums/:id, /about, /admin. /tracks и /tracks/:id — алиасы для треков.

Трек → артист и альбом. Артист → все его альбомы и треки. Альбом → артист и список треков. Детали трека → другие треки альбома или артиста. Название всегда открывает детали, кнопка play всегда воспроизводит. Ссылки и кнопки не вложены друг в друга. Поиск в каталоге учитывает названия, артистов и альбомы; запрос хранится в URL.

Плеер живёт выше маршрутов и не прерывается при навигации. Очередь определяется списком, из которого начато воспроизведение: каталог, артист, альбом или подборка. Следующий трек берётся из очереди; в конце выбирается случайный доступный трек каталога, кроме текущего, если есть выбор. Автоматическое завершение использует тот же переход. Назад возвращает фактически проигранный трек; если история пуста — предыдущий в очереди. Единственный трек может повториться. Пустой каталог отключает управление.

## Waveform

wavesurfer.js рисует амплитуды реального аудио. Волны загружаются при приближении к viewport, результаты декодирования кэшируются с ограничением размера. Один HTMLAudioElement отвечает за воспроизведение; визуализации не запускают независимые аудиопотоки. Нажатие на waveform запускает выбранный трек с указанного времени; активные визуализации синхронизируются с плеером. Доступный range обеспечивает перемотку клавиатурой. При ошибке декодирования остаётся обычная перемотка: выдуманные амплитуды не показываются.

## Адаптивность и доступность

Сетки: 4 колонки на широком экране, 2 на планшете, 1 на маленьком телефоне. Entity hero превращается в вертикальный блок. Мобильный плеер — два ряда: метаданные и управление, затем прогресс. Громкость скрыта на телефоне, очередь доступна. Минимальная область управления 44 px. Видимый focus, aria-label у иконок, alt для содержательных изображений, aria-current у активной навигации. Системная настройка prefers-reduced-motion отключает декоративное движение. Анимации только transform / opacity, 160–220 ms; бегущая строка медленная, останавливается при наведении. Никаких постоянных миганий.

## Реализация

React Router — адресуемые страницы и история. TanStack Query — запросы, кэш и повторная загрузка. Zustand — единое состояние очереди и плеера. wavesurfer.js — waveform. CSS custom properties — источник визуальных токенов. Административные формы сохраняют существующую авторизацию и операции, их оформление приводится к токенам. Новые комментарии в код не добавляются.
